KivuFoot — lot PDF officiel et moteur sportif

Ce paquet contient les fichiers modifiés du backend et du frontend.
Il inclut :
- génération automatique du PDF après validation officielle d'un match ;
- routes de consultation et téléchargement des PDF ;
- fiche PDF joueur ;
- stockage Supabase Storage dans le bucket documents-kivufoot ;
- modèles, routes et services du moteur sportif P0 ;
- interface publique avec les liens de téléchargement.

Avant d'utiliser la génération PDF sur Render, vérifier les variables serveur
SUPABASE_URL et SUPABASE_SERVICE_ROLE. Ne jamais les publier dans GitHub ni
les envoyer dans le chat.
